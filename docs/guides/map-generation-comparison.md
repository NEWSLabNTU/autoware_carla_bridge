Comparison of Lanelet2 maps generated by `carla_map_gen` (CommonRoad Scenario
Designer) against pre-converted TUMFTM reference maps in
`data/carla-autoware-bridge/`.

Generated from CARLA 0.9.16 OpenDRIVE files using `--xodr` offline mode.

## Consistent Patterns Across All Maps

### Improvements Over Reference

1. **Traffic light regulatory elements properly typed**: Generated maps have
   `subtype=traffic_light` on regulatory elements. Reference has empty subtypes.

2. **Traffic light way subtypes fixed**: Generated maps use
   `subtype=red_yellow_green` (the canonical Autoware value). Reference uses
   either empty strings or `red_redYellow_green_yellow` (Town10).

3. **MGRS codes present**: All generated maps have `mgrs_code` on nodes.
   Town03 reference was missing them entirely.

4. **Local coordinates**: Both generated and reference have `local_x`/`local_y`
   on all nodes.

### Expected Differences

1. **Lanelet subtype classification** (road vs walkway vs none): CommonRoad
   classifies lanelets with curbstone boundaries as `walkway`, while TUMFTM
   classified many of these as `road`. Our post-processor reclassifies
   shoulder lanelets (between road and walkway) back to `road`, but some
   classification differences remain. This does not affect Autoware path
   planning, which uses lanelet topology, not subtype labels.

2. **line_thick ways** (Town03, Town05, Town10HD): CommonRoad generates
   `line_thick` way types for solid lane markings. TUMFTM used only
   `line_thin` or untyped ways. These provide richer lane marking
   information.

3. **stop_line ways** (Town03, Town05, Town10HD): Reference has `stop_line`
   ways that CommonRoad does not generate. These are not critical for
   Autoware operation.

4. **Extra regulatory elements** (Town03, Town05, Town10HD): CommonRoad
   generates more traffic_light regulatory elements than the reference.
   These represent additional traffic light associations that were not
   captured by the TUMFTM converter.

## Per-Map Details

### Town01 (Simple Grid)

  types stripped, 36 orphan ways removed, 64 shoulders reclassified
- **Subtype diff**: +19 road, +22 walkway, -41 none
- **Verdict**: Excellent. Structural match, only subtype classification diffs.

### Town02 (Simple T-junctions)
- **Lanelets**: 216 = 216 (exact match)

- **Subtype diff**: +16 road, +15 walkway, -31 none
- **Way diff**: +2 line_thin ways (minor geometry difference)
- **Verdict**: Excellent. Near-identical structure.

### Town03 (Complex with Tunnels/Parking)
- **Lanelets**: 1232 vs 1210 (+22, +1.8%)
- **Post-processing**: 38 TL fixes, 144 empty speed_limits removed, 410 way
  types stripped, 151 orphan ways removed, 221 shoulders reclassified
- **Extra elements**: +84 line_thick ways, +94 line_thin ways, +78 relations
- **Missing**: 7 stop_line ways (reference-only)
- **Notes**: Town03 has parking areas (118 "parking" road object warnings) and
  bidirectional lanes. CommonRoad generates additional lanelets for some of
  these complex geometries. Crosswalk count matches exactly (73).
- **Verdict**: Good. Extra lanelets from complex geometry, crosswalks match.

### Town05 (Highway + Urban)
- **Lanelets**: 1029 = 1029 (exact match)

- **Subtype diff**: +108 road, +39 walkway, -147 none (largest shift)
- **Notes**: Largest subtype reclassification delta. The highway sections have

### Town10HD (Dense Urban)

- **Way diff**: -8 ways (fewer than reference)

- **Missing**: 21 stop_line ways, 4 traffic_sign ways, 1 right_of_way
- **TL subtype**: Reference used `red_redYellow_green_yellow` (non-standard),

- **Verdict**: Good. Lanelet count matches, TL subtypes improved.

## Conclusion

The `carla_map_gen` tool produces Autoware-compatible Lanelet2 maps that are
structurally equivalent to the TUMFTM reference maps:

- **Lanelet counts match** for 4 out of 5 maps (Town03 has +1.8% more due to
  complex geometry)
- **Crosswalk counts match exactly** across all maps
- **Traffic light metadata is improved** (proper subtypes vs empty/non-standard)
- **Remaining differences** are subtype classification (road/walkway/none) which
  does not affect Autoware path planning

### Missing Features (vs Reference)

These are present in the TUMFTM reference but not generated by CommonRoad:
- `stop_line` ways (Town03/05/10)
- `right_of_way` regulatory elements (Town05/10)
- Some `traffic_sign` ways (Town05/10)

These are non-critical for basic Autoware operation but may be needed for
advanced traffic rule compliance.
